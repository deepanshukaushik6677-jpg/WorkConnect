# LocalHire intro website

A responsive single-page landing/intro website for a local hiring and services marketplace.

## Files
- `index.html` — page structure and content
- `styles.css` — responsive visual system
- `app.js` — interactions and demo data

## Run locally
Open `index.html` directly in a browser, or serve the folder:

```bash
python -m http.server 8080
```

Then open `http://localhost:8080`.

## Current prototype interactions
- Hire vs. work intent switch
- Search form demo
- Category selection feedback
- Worker result filters
- Hirer/worker workflow tabs
- One-time/temporary/regular job type switching
- Sign-in / join onboarding modal
- Request button demo
- Mobile navigation
- FAQ disclosure
- Toast notifications
- Reduced-motion support

This is a frontend concept/prototype; no backend, authentication, database, real maps, payments or messaging service is connected yet.
